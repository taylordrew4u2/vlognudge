# Screenshots

The main README embeds the five images below. To regenerate them, run
`scripts/capture_screenshots.sh` on a Mac, or push to the `screenshots` branch
so the **Screenshots** workflow captures and commits them.

| File | Screen | Launch arguments |
|------|--------|------------------|
| `today.png` | Today — next nudge + daily clip progress | `-ScreenshotMode -ScreenshotTab 1` |
| `home.png` | Home — progress ring + albums | `-ScreenshotMode -ScreenshotTab 0` |
| `timeline.png` | Timeline — calendar of captured clips | `-ScreenshotMode -ScreenshotTab 2` |
| `settings.png` | Settings — frequency, active window, quiet hours | `-ScreenshotMode -ScreenshotTab 4` |
| `settings-places.png` | Settings — capture, bad-day mute, permissions & places | `-ScreenshotMode -ScreenshotTab 4 -ScreenshotSettingsPlaces` |
